# GradeX

**Student portal for SRM University — timetable, attendance, marks, and academic tools in one place.**

🔗 **Live site:** [gradex.bond](https://gradex.bond)

---

## About

GradeX is a full-stack web app for SRM students: view schedule, track attendance, check marks, and use academic utilities from a single dashboard. Built with a focus on reliability and a clean, fast experience on web and mobile.

## Highlights

- **Single dashboard** — Timetable, attendance, marks, calendar, and food/mess info
- **SRM integration** — Secure, official data flow for authenticated students
- **Real-time features** — Live components where it matters
- **PWA-ready** — Usable on phones and desktops

## Tech (high-level)

React, Node.js, Convex (backend), Docker. Hosted on a VPS with Nginx and HTTPS.
